# Movie Box BLC: Where to Watch

Android Studio starter project using Kotlin, Jetpack Compose, OkHttp, and TMDB API v3.

## Features
- Trending, popular movies, popular TV, upcoming movies
- Search movies and TV shows
- Detail pages with synopsis, rating, cast, and country-specific watch-provider data
- Local watchlist stored on the device
- Dark interface and bottom navigation
- No movie streaming or downloading

## Setup.

## Important
- Watch-provider data is powered by JustWatch and requires attribution. Provider data can be missing for some titles/regions.
- This starter does not include authentication, cloud sync, trailers playback, ads, analytics, or a streaming player.
